U.S. Government Notices API

Fetch Federal Register documents as JSON. The API returns document records published by the U.S. government, ordered newest first.

Endpoint

GET /info

With no options, this returns the latest 30 documents. Each response has a count field and a notices array of Federal Register records. 

{
  "count": 30,
  "notices": [{ "title": "...", "publication_date": "..." }]
}

Options

  • last: return that many latest documents (1–1000). Example: /info?last=10
  • start and end: return every document published within the inclusive date range, formatted as YYYY-MM-DD. Example: /info?start=2026-09-01&end=2026-10-01

Date range results are paginated through the Federal Register API. Provide both dates; last only applies when no date range is supplied. Invalid options return a JSON error with HTTP 400.

Source: Federal Register API.
